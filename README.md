# SeatWatch

SeatWatch watches full UBC course sections and emails students the moment a seat opens up. A C++ worker polls seat counts on a schedule; a Java/Spring Boot API owns subscriptions, opening detection, and notification delivery.

Status: in progress.

Built incrementally with Claude Code as a pair-programming tool, one commit at a time — see [`PLAN.md`](PLAN.md) for the plan and reasoning behind each step.
